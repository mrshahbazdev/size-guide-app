# Size Guide + Fit Finder — App Store Listing

## App name
Size Guide + Fit Finder

## Short description
Help customers choose the right size with beautiful size charts, a fit finder quiz and measurement-based recommendations.

## Full description
Reduce returns and boost confidence with Size Guide + Fit Finder. Merchants can create unlimited size charts, assign them to products, collections, types or tags, and display them as a button, inline table or sticky tab. The fit finder asks shoppers a few quick questions and recommends the best size. Shoppers can also enter their own measurements to get a personalized recommendation.

**Key features:**
- Unlimited size charts with priority-based matching
- cm/inch unit toggle on the storefront
- Multiple display modes: button modal, inline table and sticky drawer
- Fit finder quiz with step-by-step UX
- Measurement-based size recommendations
- Collection, type, tag and product-specific assignment
- CSV import/export for bulk chart management
- Analytics dashboard: opens, submissions and top sizes
- Multi-language support (EN, DE, FR, ES)
- Fully customizable colors, padding, border radius and alignment
